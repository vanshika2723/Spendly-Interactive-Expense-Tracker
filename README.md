# 💜 Spendly –**&#x20;Interactive Expense Tracker**

**Spendly** is a modern and responsive personal finance dashboard designed to help users manage daily expenses, track monthly spending, set budgets, and monitor savings goals from one place.

It features a premium Midnight Navy and Electric Violet theme with interactive charts and an easy-to-use interface.

## ✨ Features

- **Dashboard Overview** – View total expenses, monthly expenses, and transaction count.
- **Expense Management** – Add, edit, and delete expense records.
- **Expense Categories** – Organize transactions by category.
- **Search & Filters** – Search expenses and filter by category, date, or date range.
- **Sorting** – Sort expense records according to available options.
- **Interactive Charts** – Visualize category-wise and monthly spending.
- **Budget Tracker** – Set a monthly budget and monitor remaining funds.
- **Savings Goals** – Create savings goals and track progress.
- **Dark Mode** – Switch between light and dark themes.
- **PDF Reports** – Generate expense reports for a selected month.
- **Data Backup** – Export and import expense data using JSON files.
- **Responsive Design** – Use the dashboard on desktop, tablet, and mobile screens.
- **Local Storage** – Save financial data in the browser.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Open the Project

Open the project folder in Visual Studio Code.

### 3. Run the Application

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

> An internet connection may be required to load the Chart.js, jsPDF, and Google Fonts resources through their external CDNs.

## 📊 How to Use

1. Open the Spendly dashboard.
2. Add an expense by entering its title, amount, category, date, and other details.
3. Review expenses in the transaction list.
4. Search, filter, sort, edit, or delete transactions as needed.
5. Set a budget to monitor monthly spending.
6. Create savings goals and track progress.
7. View charts to understand spending patterns.
8. Generate a monthly PDF report.
9. Export a JSON backup to save your data or import a previously exported backup.

## 💾 Data Storage

Spendly uses the browser's **LocalStorage** to persist application data.

- Data is stored locally in the current browser.
- Clearing browser storage may remove saved application data.
- Data is not automatically synchronized across devices.
- Export a JSON backup regularly to protect your records.

**Privacy note:** This is a frontend project, not a banking application. Avoid entering passwords, bank account credentials, or other sensitive financial information.
